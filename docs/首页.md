# 首页数据看板设计

首页（`/`）用于查看知识分享活动的次数、报名人数、签到人数和海报访问量。

沿用 shadcn-admin 的侧栏、顶部栏、卡片、图表和表格样式，支持浅色和深色主题。页面先显示筛选和指标卡，下方用一张图表展示活动与分享趋势。海报码访问量和分享带来的报名、签到按活动汇总，显示在「活动」列表。内容推送有独立页面 `/content-push`。

## 首页元素

| 元素           | 展示内容与交互                                                                               | 为什么需要                               |
| -------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------- |
| 标题           | 数据看板                                                                                     | 标识当前页面。                           |
| 筛选栏         | 默认「本周」，可选上周或自定义日期，支持筛选活动。                                           | 既能看整体表现，也能查看单场活动的统计。 |
| 首屏指标卡     | **活动次数、报名人数、签到人数、海报访问量**。有值时附上签到率。                             | 快速掌握活动规模、到场情况和海报传播量。 |
| 活动与分享趋势 | 按日展示活动报名、活动签到、海报码访问量、分享报名和分享签到。点击图例可显示或隐藏对应指标。 | 便于比较同一天的活动参与和分享效果。     |

## 统计口径

日期按北京时间。默认从周一到周日统计。本周概览按记录的发生时间统计。上周报名、本周签到的记录计入本周签到人次。

| 指标             | 计算方式                                                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 活动次数         | 所选范围内按活动日期计数。                                                                                                            |
| 海报访问量       | 汇总所选范围内通过活动海报链接的访问次数。                                                                                            |
| 报名人数         | 按活动统计有效报名，同一人在同一活动中重复提交只计一次。跨活动汇总时，同一人参与多场计为多次，汇总卡片的说明注明按有效报名人次统计。  |
| 签到人数和签到率 | 同一活动内每位成功签到的报名者只计一次。签到率按同一场活动的成功签到报名者 ÷ 有效报名者计算。跨场汇总使用分子和分母各自合计后再相除。 |

## 页面状态和操作

- 切换活动后，指标卡和活动与分享趋势图同步更新。
- 活动尚未开始时提示「签到未开始」。查询成功且确实没有记录时显示 `0`。签到率分母为零或数据尚未接入时显示 `—`，并注明原因。加载失败显示重试入口。
