# 微信小程序端页面设计

小程序底部导航依次为「首页」「活动」「分享」「我的」，默认进入「首页」。首页顶部是「活动 · 分享 · 成长」的主题头图，下方依次展示活动回顾 Banner、近期活动和近期分享。扫描活动海报时，直接进入对应活动的报名页。

| Tab  | Taro 页面                | 用户可以做什么                                     |
| ---- | ------------------------ | -------------------------------------------------- |
| 首页 | `pages/home/index`       | 浏览活动回顾、近期活动和近期分享，快速进入各板块   |
| 活动 | `pages/activities/index` | 浏览近期和往期活动，查看详情、报名、签到或生成海报 |
| 分享 | `pages/knowledge/index`  | 阅读每日保研帖子，查看原文，按主题找内容           |
| 我的 | `pages/mine/index`       | 查看我的报名、分享记录与佣金，设置内容接收偏好     |

## 首页

首屏为沉浸式头部（自定义导航栏）：渐变蓝色背景、标题「活动 · 分享 · 成长」、副标题「连接更大的世界」，状态栏高度动态适配。头部下方叠加活动回顾 Banner 轮播，卡片含主题图、活动标签、标题、副标题和「查看回顾」按钮。

Banner 下方是两张白色卡片：

- **近期活动**：标题左侧带蓝色竖条，右侧「查看全部」跳活动 Tab；每项展示缩略图、标题、日期、地点、状态标签（报名中/即将开始）、报名人数和操作按钮。
- **近期分享**：结构同上；每项展示缩略图、标题、摘要，以及作者头像、昵称、发布时间、浏览量和点赞数。

## 统计（二级页）

从个人中心等入口进入，不在底部导航。

顶部展示「本周」「本月」「全部」筛选，下面用四张卡片展示个人报名、签到、海报访问和分享带来的报名。报名与签到按活动去重，海报访问按通过本人海报打开活动入口的次数累计，分享报名按归因给本人的有效报名统计。点卡片进入对应记录，沿用当前时间范围。

指标下方展示最近一场已报名且尚未结束的活动。卡片显示活动标题、分享人、日期和报名状态，主按钮根据状态显示「查看报名」或「立即签到」。还没有报名时显示「浏览活动」。待接入的数据用 `—`，查询成功且没有记录时显示 `0`。

## 活动

列表分为「近期活动」「往期活动」。卡片只依赖后台已维护的活动标题、分享人和活动日期。近期活动可以进入详情报名，往期活动可以查看详情，有回顾链接时展示「查看回顾」。

- **活动详情**（`pages/activity-detail/index`）展示标题、分享人、日期和当前状态，底部保留一个主要操作。分享入口可生成个人海报。
- **报名**（`pages/activity-join/index`）从活动详情或海报进入。顶部展示活动信息，表单只填姓名和手机号。提交成功后展示报名凭证和「查看我的报名」。重复进入时，已有有效报名的用户直接看到报名状态。
- **签到**（`pages/activity-check-in/index`）从活动详情或「我的报名」进入。已有有效报名且签到窗口开放时可提交，成功后展示时间。重复进入时显示「已签到」。签到窗口开放前或关闭后展示原因和返回活动的入口。
- **制作海报**（`pages/activity-poster/index`）可从活动详情进入，也可以在「我的分享」查看已有海报。标题默认使用活动标题并可修改，分享人和活动日期来自活动信息，右下角是报名用的小程序码。提供保存海报和转发活动入口。

## 知识分享

首屏展示最新帖子，下方按发布时间倒序展示历史内容。卡片显示标题、摘要、主题和发布日期。主题可先用「夏令营」「预推免」「面试经验」，点卡片进入文章详情（`pages/knowledge-detail/index`）。详情页展示正文或摘要，有原文地址时提供「查看原文」。知识帖子与往期活动各自保留入口。

## 我的

顶部展示账号状态，下面按用户要找的事项排列。

| 入口         | 展示内容                                               |
| ------------ | ------------------------------------------------------ |
| 我的报名     | 活动、报名状态、签到状态，点击返回活动或签到页         |
| 我的分享     | 活动海报、访问量、分享报名、分享签到，支持再次保存海报 |
| 我的佣金     | 每笔活动归因和结算状态                                 |
| 内容接收设置 | 可选接收渠道和主题，展示当前订阅状态                   |

## 扫码与数据衔接

1. 海报上的报名码携带邀请码，打开报名页后由服务端解析对应的活动和分享人。用户从活动列表进入也可正常报名。
2. 报名成功后，服务端保存活动、报名者、报名时间与已有的邀请归因。以同一用户在同一活动的一条有效报名为统计依据。重复扫码或重复提交沿用已有报名。
3. 签到关联原报名，记录签到时间。小程序个人统计和管理后台看板使用同一批报名、签到和访问记录，分别按个人和活动汇总。
4. 邀请无效、活动取消或已结束时，说明具体状态，并提供「查看其他活动」。

## 首版范围

Taro 首版可用 Mock 数据串通四个 Tab 和报名、签到、海报预览流程。后台仍只填写标题、分享人、活动日期。演示用签到状态来自 Mock，真实签到窗口需要后台提供开放状态。佣金结算和内容接收渠道待规则和接口确认后开放，首版使用对应的页面空态。
